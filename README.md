## Tech Stack:
- **React 19** + **Vite 7**
- **React Router DOM** — multi-page navigation
- **EmailJS** — contact form without backend
- **React Icons** — icons
- **Normalize.css** — CSS reset
- **Pure CSS** — no frameworks

## Features
- **Multi-page navigation** — Home, About, Services, Booking, Policy, Terms
- **Services Modal** — interactive hover-based tabs that dynamically update a
  full-background image and service description (Voice Recording, Track Mastering,
  Audio Editing, Track Mixing, Track Recording, Rehearsal Room)
- **Album Slider** — custom-built carousel (no library) with auto-scroll every
  3 seconds, pause on hover, infinite loop, and prev/next navigation buttons
- **Socials Popup** — per-album social links popup
- **Booking page** — session reservation for the studio
- **Contact form** powered by EmailJS — no backend required
- **404 page** — custom Not Found page
- **Privacy Policy & Terms** — dedicated legal pages
- **Fully responsive design** — mobile, tablet, and desktop
- **Client-side routing** with React Router DOM
- **Optimized images** via ImageKit CDN
